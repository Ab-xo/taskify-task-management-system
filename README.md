# Taskify Task Manager

A full-stack task management application for creating, organizing, tracking, and completing daily work.

## Features

- Task creation and editing
- Status and priority workflows
- Separate frontend and backend applications
- REST API architecture
- Responsive task-management interface

## Technology

- JavaScript and React
- Node.js and Express
- MongoDB
- HTML and CSS

## Getting started

Install dependencies in the project root and application directories according to the package scripts, configure the database connection, then start the frontend and backend services.

```bash
npm install
npm run dev
```

Keep database credentials and API secrets in environment variables.
